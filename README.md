# 🎯 Guess the Number Game

## About the Project
This is a simple and interactive Guess the Number game created using HTML,CSS and JavaScript.The game generates a random number,and the player has to guess the correct number to win.

## Technologies Used
- HTML
- CSS
- JavaScript

## Features
- Random number generation
- User-friendly interface
- Interactive guessing experience
- Instant feedback for each guess
- Simple and fun gameplay

## How to Play
1. Enter your guessed number in the input field
2. Click the Guess button
3. Follow the hints to find the correct number
4. Keep guessing until you get it right!

- Handling user input
